# Portfolio

Static portfolio (HTML/CSS/JS), no build step, no dependencies.

1. Edit **data.js** with your information.
2. Edit the SEO block at the top of **index.html** (title, description, URLs).
3. Put your photo at `assets/profile.jpg` and your CV at `assets/CV.pdf`.
4. Push to GitHub → Settings → Pages → Deploy from branch `main` / root.

Preview locally: open `index.html`, or run `python -m http.server` and visit http://localhost:8000
